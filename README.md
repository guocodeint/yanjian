# 研笺 · 文献研究助手

研笺帮助学生围绕研究问题检索和筛选 Europe PMC 文献，对照原文整理论据，并生成带逐句引用的研究简报。

## 启动

需要 Node.js 24（使用内置 SQLite）。在本目录运行：

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:8787 ，点击“创建账号”。用户名为 3–32 位字母、数字、下划线或连字符；密码至少 10 个字符。首版不提供找回密码。

在 Windows 上也可双击 `启动产品.cmd` 启动应用。手动运行生产构建：

```powershell
npm run build
$env:NODE_ENV='production'
npm start
```

## AI 配置

登录后打开「个人设置」，填写个人 DeepSeek API 密钥和模型 ID。保存立即生效，留空密钥可仅修改模型。新账号默认未配置 AI，绝不继承主机环境变量。可随时清除密钥。

AI 建议检索词和证据生成分别触发真实付费请求。没有密钥时，英文检索、手工证据表、模板简报和导出仍可使用；不以模板假装 AI 成功。

## 中文阅读

在文献工作台点“翻译标题”，每次翻译最多 20 篇尚无译文的题名。在“查看摘要与备注”中点“翻译为简体中文”，阅读中文译文和外文原文。使用个人设置中的 DeepSeek 密钥和模型，手动发起时消耗个人额度。译文随当前账号的研究项目保存，也随项目 JSON 备份。无摘要文献仅能翻译题名。引用及摘要依据仍使用原文，数值和专业术语以来源为准。

## 相关性与逐句引用

展开“排序概念”可添加同义词并指定核心概念。默认基础排序使用题名、摘要与主题词，按相关度降序；按需使用个人模型核对前 20 篇。若已取结果缺少核心概念，可以将该概念加入英文检索式并重新搜索。检索记录可展开查看条件、来源、时间及候选数。

证据矩阵中的位置按钮打开原句和上下文。简报句末的上标可跳到相应证据；人工修改的陈述标记待复核。历史项目保留已有引用粒度。排序对照与浏览器验证结果见[测试记录](docs/VERIFICATION.md)。

## 五步体验

1. 注册或登录，阅读使用说明，填写自己的研究问题和英文检索词。
2. 点击“开始检索”，查看真实题录与摘要，选取最多 10 篇文献。
3. 点击“手工整理”或“生成证据与简报”，核对证据原句并编辑。
4. 打开研究简报，修改内容，点击引用检查出处。
5. 导出 CSV、Markdown、JSON 或打印 PDF；在“账号研究库”恢复记录和下载已保存文件。

首次使用研究库为空。文献检索和分析前获取摘要均由部署服务器访问 Europe PMC；服务器连接中断时仍可阅读已存入账号的摘要。外部原文链接使用访客网络。

## 数据、账号与存储

- 数据库：`data/research.sqlite3`，保存用户、会话、研究记录及导出元数据。
- 文件存储：`data/objects/`，保存导出的 CSV、Markdown 和 JSON 快照；浏览器打印 PDF 保存在用户选择的位置。
- 密码使用随机盐和 scrypt 哈希；登录会话为随机令牌，数据库仅存哈希，Cookie 为 HttpOnly、SameSite=Strict，有效期 7 天。
- 所有研究与文件读写由服务端依据当前登录账号限定，不接受客户端提供的用户 ID。
- 保存采用修订号乐观锁；另一设备更新后会提示冲突，可在简报页面下载本地备份再刷新，不会静默覆盖。
- 换浏览器登录同一账号可恢复服务端记录。跨设备需访问同一部署地址；本地 127.0.0.1 本身不能从其他设备访问。
- 删除项目同时删除关联的导出文件。清理浏览器 Cookie 只会退出登录，不会删除账号研究。

备份：先停止服务，再同时备份整个 `data` 目录。个人凭据以 AES-256-GCM 加密。本地默认在 data/ai-master.key 保存解密材料，备份须限制访问，不能分享 data 目录。云端通过平台秘密配置持久的 YANJIAN_MASTER_KEY（32 字节，64 位十六进制），不可随实例轮换。数据库与解密密钥应分别受控保管。运行时 SQLite 使用 WAL，不要仅复制正在写入的主数据库文件。

## 科研与发布边界

支持 Europe PMC 题录、摘要和可读取的开放全文片段。引用存在和原句匹配校验不能证明语义正确；AI 输出及人工修改都需核查。不提供疗效判断、临床建议或溶解度预测。

用户材料视为数据，不执行其嵌入指令。来源链接由检索结果构造，模型不能新增来源。密钥仅通过设置表单提交，服务端不回显，不写入研究文件或日志。

请求限流与 AI 每日额度按服务进程计数，重启后重置。
