## 拟人仿真场景

这是 Playwright 驱动的自动化操作，使用测试账号和合成阅读备注，不是真实受访者反馈。

1. 新手：注册、提交空检索，获得中文提示后打开公开文献快照。
2. 阅读者：打开摘要、输入人工备注、按 Escape 返回工作台。
3. 学生：选择两篇、编辑证据、填写简报，保存并下载项目备份。
4. 换设备：第二浏览器恢复记录并修改；旧页面提交触发冲突，下载本地备份后刷新恢复服务器新版本。
5. 误操作：导入损坏 JSON 被拒绝，原记录保留。
6. 结束工作：查看账号导出文件、退出；原会话无法再访问私人研究。

发现并修复：低对比度辅助文字、手机导航入口不够明显、坏 JSON 的技术错误信息、删除项目后导出列表未刷新。修复后已重跑场景及扫描。

## 数据与质量边界

真实分析通过文献标识和原句定位检查，并抽查三个摘要。部分原文自身措辞含糊；引用匹配不证明解释在科研语义上正确。产品保留原句、AI 原始版本和人工修订，不显示专业审核通过。

AI 有非确定性。一次请求遗漏依据字段，被系统拦截并保留已有研究；随后改为模型返回句子索引、服务端还原原句，真实请求重新验证成功。缺失依据不会被编造成有效结果。

无历史视觉基线，视觉回归结论为 INCONCLUSIVE；本次是截图与布局检查。自动无障碍通过不等于完成屏幕阅读器或 WCAG 合规认证。未进行真实设备性能、长期压力、灾难恢复或公网部署验证。

## 复现

先 npm ci、npm run build、npm test、npx playwright install chromium。

终端一：

```powershell
$env:NODE_ENV='production'
$env:PORT='8790'
$env:DATA_DIR='./artifacts/qa-database'
npm start
```

终端二：

```powershell
$env:TEST_URL='http://127.0.0.1:8790'
npm run test:api
npx tsx tests/personas.ts
npm run test:browser
# 可选真实 AI 请求，会计费
$env:LIVE_AI='1'
npm run test:browser
```
